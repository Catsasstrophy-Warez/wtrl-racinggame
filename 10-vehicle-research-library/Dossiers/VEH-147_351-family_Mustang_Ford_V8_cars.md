## Cross-reference note (technical-category pass, not a standalone vehicle)
This dossier is a real Ford engine-family reference (351 Windsor / 351 Cleveland small-block V8), not a distinct vehicle. It exists to hold family-level engineering detail that individual Mustang-generation dossiers shouldn't have to repeat.

**Real family specs (web-verified this pass, not previously in this library):**
- **351 Windsor (351W):** 4.00 in bore x 3.50 in stroke = 351 cu in (5.8L). Introduced in the Mustang for 1969. ~8.6 million 351W units built 1969-1996 across the Ford lineup.
- **351 Cleveland (351C):** same 4.00 in x 3.50 in bore/stroke, actual displacement 351.9 cu in (5,766 cc), but a physically different, lower/wider block with different heads. Entered production July 1969 for the 1970 model year and replaced the 351W in the Mustang/Cougar for MY1970-1973.
- Both engines are part of Ford's "335 engine" (Cleveland) and small-block Windsor families respectively — related but not interchangeable blocks despite sharing bore/stroke.

**Cross-reference check against this library's already-researched Mustang dossiers:** none of the currently hard-specced classic Mustang dossiers (VEH-016 1965 GT350: 289 ci; VEH-018 1967: 200 ci I6/289 ci/390 ci FE; VEH-019 1967 GT500: 428 ci FE; VEH-020 1968 GT390 Bullitt: 390 ci FE; VEH-022 1969 Mach 1: 428 ci; VEH-023 1969 Boss 429: 429 ci "semi-hemi") actually documents a 351-cubic-inch engine as its verified configuration. The 351 was a mid-tier option across 1969-1973 Mustangs (Mach 1, Grande, base fastback) that this library has not yet built a dedicated dossier for. Honest conclusion: **no existing VEH- dossier in this library currently carries a verified 351 application** — this category currently stands alone as engine-family reference data pending a future 1970-1973 Mustang dossier that would actually mount it.
