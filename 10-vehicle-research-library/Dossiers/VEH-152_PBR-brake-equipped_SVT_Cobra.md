## Cross-reference note (technical-category pass, not a standalone vehicle)
The PBR twin-piston front brake package is a real, specific hardware spec already sourced in this project's own corpus, not a new discovery this pass — cited directly rather than re-invented.

**Already-sourced figure (from `racinggame/07-content-resolution/52-CONTENT-RESOLUTION-PASS-1.md` Part 2.3, itself traced to `47-PARTS-PRICING.md` Part 5):** for the mid-90s 4V DOHC top-trim Mustang (the 1996-1998 SVT Cobra, 305 hp @ 5800 rpm / 300 lb-ft @ 4800 rpm) — **13 in vented front rotors with PBR twin-piston calipers, 11.65 in vented rear rotors with single-piston calipers.** That document frames this as "real period spec for this specific trim."

**Web cross-check this pass:** PBR (an Australian brake manufacturer, part of the former Bendix/PBR group, now part of ZF/TRW lineage) was a documented OEM caliper supplier to Ford SVT programs in this era; this pass did not locate a primary Ford/SVT engineering document giving the exact caliper piston bore diameter or clamping force beyond the rotor/caliper-type description already in `52-CONTENT-RESOLUTION-PASS-1.md`, so no additional hard number is added beyond what the corpus already carries — extending it further would require an SVT service manual or period brake-industry trade source not accessed in this pass.

**Cross-reference:** the vehicle this spec applies to is **VEH-030 (1996-1998 Mustang SVT Cobra, 4.6 DOHC)** in this library's numbering — check that dossier for the full vehicle-level context; **VEH-028 (1993 SVT Cobra, 302 Windsor)** is the earlier Fox-body Cobra and used different Fox-platform brake hardware, not this PBR package.
