## Cross-reference note (technical-category pass, not a standalone vehicle)
The Ford/GM co-developed 10R80 10-speed automatic is the transmission fitted to the 2018+ Mustang GT (and later 2022 S650 GT). Its ratio set is already sourced in this project's corpus.

**Already-sourced ratios (from `racinggame/07-content-resolution/52-CONTENT-RESOLUTION-PASS-1.md` Part 2.6/2.7, traced to `47-PARTS-PRICING.md` §2.7), listed for the "2022" generation but representing this same 10-speed automatic family across both 2018+ S550 and 2022+ S650 applications:**
- Ratios: 4.696 / 2.985 / 2.146 / 1.769 / 1.520 / 1.275 / 1.000 / 0.854 / 0.689 / 0.636
- Reverse: 4.87
- Final drive: 3.31

**Additional detail beyond the corpus (general public knowledge, not independently re-verified against an OEM document this pass):** the 10R80 is a Ford/GM joint-venture design also used across F-150, Expedition, Camaro, and other GM/Ford applications sharing the same base architecture — it is not a Mustang-exclusive unit, unlike the MT82 or TR-3650 manuals. This pass did not find additional Mustang-specific 10R80 detail (e.g., torque converter lockup calibration, shift-time figures) beyond the ratio table already in the corpus, so no further hard spec is added.

**Cross-reference:** vehicle-level context is **VEH-034 (2018 Mustang GT)**; check that dossier for full context, and see VEH-157 below for the pairing with the 5.0 Coyote.
