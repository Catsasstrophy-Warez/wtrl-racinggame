## Cross-reference note (technical-category pass, not a standalone vehicle)
This dossier is a real factory-offered forced-induction option, not a distinct vehicle: Paxton's supercharger kit as sold through Shelby American on the 1966-1967 GT350.

**Real specs found this pass (web-verified, no existing library citation for this before):**
- Offered as factory option code "S" starting 1966; only ~11 built in 1966, ~35 in 1967.
- Boosted the naturally-aspirated GT350's 289 from a factory 306 hp rating to a documented 390+ hp on the supercharged package, with some sources citing figures over 440 hp and enthusiast-tuned examples reaching 400-450 hp. Sources disagree on the precise peak figure (390 vs. 440), which is flagged honestly here rather than resolved to a single number — both figures come from secondary/enthusiast-grade sources (Silodrome, Street Muscle Mag, Newport Car Museum), not a factory spec sheet, so treat this as directional (roughly a 30-45% power increase) rather than a precise WTRL calibration target.
- No period source found in this pass documenting a factory Paxton kit specifically for the 1967 GT500 (428 FE big-block) — comparisons found only contrast the blown GT350's output against the naturally-aspirated GT500, not a Paxton-equipped GT500.

**Cross-reference against already-researched dossiers:** the relevant base cars are **VEH-016 (1965 GT350, 289 ci, naturally aspirated only — no Paxton option that year)** and the 1966-67 GT350 generation, which does not yet have its own dedicated dossier separate from VEH-016/VEH-019 in this library's current numbering. This entry should be read as the forced-induction option layer on top of the 1966-67 GT350, not a standalone car.
