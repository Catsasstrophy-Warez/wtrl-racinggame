## Cross-reference note (technical-category pass, not a standalone vehicle)
This category pairs the 5.0L Coyote V8 with the 10-speed automatic (10R80) — the modern (2018+) Mustang GT drivetrain combination. Both halves are already independently sourced elsewhere in this library; this dossier's role is to confirm the pairing rather than add new numbers.

**Engine side — VEH-033 (2015 Mustang GT / S550)** already carries the Gen-2 Coyote's debut spec (435 hp @ 6500 rpm / 400 lb-ft @ 4250 rpm, SRC-124/SRC-125); the corpus (`52-CONTENT-RESOLUTION-PASS-1.md` Part 2.5) separately notes the 2018+ compression-increase revision reaching 460 hp. **VEH-036 (2020 Shelby GT500)** uses the related-but-distinct supercharged 5.2L Predator (flat-plane-adjacent Voodoo lineage aside, GT500 is a different engine family, not the Coyote) — relevant for cross-checking the halo end of the same generation's powertrain lineup, but not itself a Coyote/10-speed car (GT500 uses the Tremec 7-speed DCT, per VEH-036's own snapshot, not the 10-speed automatic).

**Transmission side:** see VEH-156 above for the 10R80's full corpus-sourced ratio table (4.696/2.985/2.146/1.769/1.520/1.275/1.000/0.854/0.689/0.636, reverse 4.87, final drive 3.31).

**Honest conclusion:** no new figures beyond what VEH-033/VEH-156/the corpus already carry; this entry's value is confirming the combination and pointing to the right two sources rather than duplicating them.
