# Rival roster blockout pass 1 (2026-09-20)

28 blockout `.blend` files for the 6 named rivals' vehicle generations
(Marsh 7, Reyes 5, Vogel 5, Kade 4, Osei 4, Duquesne 3), generated by
`scripts/generate_mobile_fleet.py` against `catalog_manifest.json`'s
new `"generation": "rival"` entries. This closes the previous total
gap — these 28 vehicles had zero tracked Blender assets before this
pass, despite being the actual opponent roster the player races
against.

## What this is

The same LOD0/1/2 + collision + wheel-marker blockout every other
manifest vehicle already gets — box-and-cylinder proxy geometry sized
to each generation's length/width/height/wheelbase/track/wheel-radius.
Suitable for early Unity import, physics-collider testing, and
scale/proportion checks. **Not** finished art.

## What the dimensions and generation identities actually are

**Claude's own scaffold, not sourced project canon.** The 6 rivals'
real-world "flavor" archetypes were already established in
`10-vehicle-research-library/Matrices/MASTER-VEHICLE-REGISTRY.csv`
(Marsh Constant → NSX, Reyes Aero GT → Porsche 911, Vogel Touring
Saloon → BMW M3, Duquesne Big-Block → Charger/Challenger, Osei
Lightweight → Lotus/Seven archetype, Kade Turbo Six → Skyline
GT-R/Supra-class turbo six), confirmed by the pre-existing orphaned
`marsh_nsx91.blend` in this same pipeline. But no per-generation names,
eras, or dimensions existed anywhere in the project before this pass —
the registry's own rival rows (VEH-008 through VEH-013) are single
placeholder entries, 0% populated by design.

The 28 generation IDs/eras/dimensions added to `catalog_manifest.json`
for this pass (`marsh_gen1_1991` through `kade_gen4_2023`) are
reasonable era-spanning approximations of each archetype's real-world
analog lineage, invented to fill the gap rather than sourced and
cited the way this project's other content is. **Before treating these
as canon**: a project-owner pass should (1) give each generation a
real in-fiction name (matching the hero lineage's "Crownfire
Original/King/Grand/..." naming convention, not "Marsh Gen 1"), (2)
verify/replace the approximate dimensions against actual researched
specs for the intended real-world reference cars, the way
`10-vehicle-research-library`'s hard-spec rows are sourced and graded
for the rest of the roster.
