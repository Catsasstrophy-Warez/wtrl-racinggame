# WTRL Interaction Pattern Atlas

This package contains: - 25 screen-level precedent dossiers - canonical
screen-to-system matrix - video/timestamp evidence ledger -
frame-accurate capture queue - WTRL interaction specification template -
explicit evidence-status markers to prevent invented timestamps

**Important:** The current environment can verify indexed video results,
but direct YouTube page retrieval was rate-limited/failed during this
pass. Therefore exact timestamps that could not be frame-inspected are
marked `FRAME_REVIEW_REQUIRED` rather than fabricated.
