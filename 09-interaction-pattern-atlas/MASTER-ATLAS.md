# WTRL Interaction Pattern Atlas --- Forensic Tranche 01

## Objective

Convert the 25 highest-value precedents into screen-level interaction
specifications using the canonical chain:

**player intent → screen state → input → selection feedback → mechanical
operation → simulation consequence → testing → persistence**

This atlas separates **verified evidence** from **inference**. Exact
timestamps are never invented. Where the web index exposes a video but
not frame/chapter timestamps, the timestamp ledger marks that row
`FRAME_REVIEW_REQUIRED`.

## Selection rationale

These 25 were chosen for direct leverage on WTRL's mechanical truth,
garage/service UX, dyno/setup, racing/career, mobile controls, world
preparation, construction/packaging, replay and visual presentation.

## Universal WTRL translation contract

Every accepted precedent pattern must answer: - What canonical WTRL
state owns the truth? - Which SwiftUI or RealityKit surface presents
it? - What player input changes state? - What feedback proves
selection/validity? - What deterministic simulation consequence
follows? - How does the player test the consequence? - What persists
into save/reload? - Which automated acceptance test proves the loop?
