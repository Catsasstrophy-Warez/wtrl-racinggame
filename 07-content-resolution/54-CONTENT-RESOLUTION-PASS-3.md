# Resolving the Content Gap, Pass 3: The Last Two Road Courses

**What this is.** `44-TRACK-ROSTER.md` Part 3 specified three road
course design briefs. `53` built the first (elevation-and-length,
Part 3.1). This builds the remaining two — signature-elevation-drop
(Part 3.2) and technical-and-tight (Part 3.3) — closing the road
course category of `51`'s inventory entirely: three briefs, three
built circuits.

**Both maintain every deliberate deviation `44` already specified**,
not just the general design principle — the specific things that make
each one demonstrably not a redrawn version of its real reference.

# PART 1 — The signature-elevation-drop circuit

**Rendered above.** 2.8km, nine corners, one signature moment — built
to `44` §3.2's brief with all four listed deviations preserved exactly:

| Deviation `44` §3.2 specified | How it's built here |
|---|---|
| Direction reversed (right-left, not left-right) | Corners 3R→3L run right-left, confirmed in the layout |
| Different elevation profile (single steep drop, not two-stage) | One continuous descent through 3R–3L, not a compression-release-compression sequence |
| Coastal cliff, not coastal hillside | The whole circuit reads as cliff-edge — tighter, more exposed geometry than a rolling hillside layout would need |
| Drop at mid-lap, not two-thirds through | Corners 3R–3L sit almost exactly at the lap's midpoint (corner 3 of 9, roughly a third by count but positioned at the elevation midpoint of the lap) |

**The rest of the lap exists to set up and recover from that one
moment**, matching real circuits built around a single signature
corner: a run-up sequence (1–2) that builds speed into the blind
entry, and a longer recovery-and-return sequence (4–9) that's
deliberately less memorable — the signature corner is supposed to be
the thing players talk about, and a lap full of equally dramatic
corners would undercut that.

# PART 2 — The technical-and-tight circuit

Built to `44` §3.3's brief: a fast uphill compression corner early,
a figure-eight or crossing element, a tight barrier-close infield
section in the second half. **Blended from multiple real patterns
rather than tracing any single reference**, which `44` already
identified as the safest possible construction — no single real
track's fingerprint survives a blend of three.

## 2.1 The layout

**3.4km, thirteen corners**, split into three distinct character
zones:

| Zone | Corners | Character |
|---|---|---|
| **Opening compression** | 1–3 | Fast, uphill, a real commitment test — flat-out entry into a corner that punishes lifting late as much as carrying too much speed |
| **The crossover** | 4–7 | A figure-eight-adjacent element — the circuit crosses back over its own earlier path via an elevated section, a layout trick real circuits use for site-footprint reasons, borrowed here for the same practical reason |
| **Tight infield** | 8–13 | Low-speed, barrier-close, street-circuit character — the tightest, most technical section in the entire track roster, shorter radii than either circuit built so far |

## 2.2 Why this pairs naturally with knockout events

`53` Part 3 used the elevation-and-length circuit for the first
knockout instance. **This circuit is the better long-term home for
knockout's multi-car elimination format** — the tight infield section
specifically rewards clean racecraft in traffic, which is exactly what
separates a genuine knockout contender from a car that's merely fast
in clear air. Worth using this circuit for knockout once more than one
knockout instance exists in the roster; `53`'s instance stands as
written, this is guidance for the *next* one.
